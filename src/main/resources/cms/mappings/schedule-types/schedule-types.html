Schedule types

The scheduler gained three things in XP 8.1: a FIXED_RATE schedule taking an ISO-8601 duration, deleteAfterRun on a ONE_TIME schedule, and a schedule.lastTaskId context attribute telling a task which task ran for its job last. Runs of one job also no longer overlap themselves.

  • runs every thirty seconds, so a second run shows the previous task id
  • lingers twenty seconds on a ten second interval, so the next run has to wait

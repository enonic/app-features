Lib Node

Exercises /lib/xp/node against a scratch repository, one operation at a time, so a failing call reports itself instead of hiding the rest. Writing nodes needs an administrator. Nothing runs until you ask for it, because the suite takes long enough to hold up a page render.

Query parameters added in XP 8.1

parent restricts a query to the direct children of a node, recursive extends it to the whole subtree, and returns has each hit carry named index fields instead of the whole node. Together they replace the deprecated findChildren. These read published content, so they run on every render.

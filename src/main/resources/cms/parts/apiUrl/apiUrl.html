apiUrl

Generates a URL to a Universal API. The form depends on where it is called: a service point under the current site, webapp or admin tool, and the /api/ form otherwise. Takes an api descriptor key, and optionally a type, a path as a string or an array of segments, and query params.

Build a link to an API

Use the API descriptor key to locate an endpoint. Add path segments and query parameters as needed.

const url = portal.apiUrl({
    api: 'com.enonic.app.features:sse',
    type: 'absolute'
});

The examples below show how the same API is addressed with different options. A generated URL does not guarantee that the API accepts the example path or that the visitor has access.

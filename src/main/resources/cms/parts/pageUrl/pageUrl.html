pageUrl

Generates a URL to a page. Called with a path or an id, optionally with a type, query params, and a project or branch to specify the context explicitly.

Link to the current page

Use the content path for a navigation link. Add query parameters to carry a search term or filter.

const url = portal.pageUrl({
    path: portal.getContent()._path,
    params: {q: 'a b&c'}
});

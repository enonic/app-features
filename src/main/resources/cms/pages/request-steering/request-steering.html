Request steering

A site mapping filter re-routes the canonical address to the variant-b child when the variant query parameter or cookie is b, by setting req.contentPath. The address bar does not change and there is no redirect. The variant carries a variantOf property pointing back at the canonical content, the same relation the variant tool in Content Studio creates.
